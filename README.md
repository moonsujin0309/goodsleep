# 굿슬립

밤의 상태에 맞는 나레이션과 배경 소리를 고르는 수면 웹앱입니다.
[서비스 열기](https://moonsujin0309.github.io/goodsleep/)

## 현행 구현 (2026-09-07)

홈의 중심은 마지막으로 시작한 밤 설정입니다. 처음에는 안내·소리·배경·기상 시각을 고르고, 다음 방문에는 저장한 설정으로 한 번에 시작합니다. 기상 시각은 지난 날짜가 아닌 다음 HH:MM으로 잡습니다. 안내는 시작할 때 새 조합을 뽑으며 이전 음성의 재생 위치를 이어 듣는 기능은 아닙니다. `설정 바꾸기`에서 기존 설정을 수정할 수 있습니다.

`소리만 듣기`는 나레이션이나 조합 이력을 사용하지 않습니다. 준비 화면에서 안내 사용 여부와 알람을 선택하며, 마지막 밤 설정에 함께 저장합니다. 알람 없이 들을 수도 있고 일시정지·종료가 가능합니다. 낮잠과 낮 명상은 밤 설정을 덮어쓰지 않습니다. 플레이어는 세션 제목·현재 문장·일시정지·종료를 중심으로 두고 음량 슬라이더는 `소리 조절`을 펼쳐 사용합니다. 홈과 준비 화면은 정적인 어두운 바탕, 재생 화면은 고른 자연 장면을 사용합니다.

반복해서 들어도 덜 익숙하게 느껴지는 경험을 목표로 합니다. 밤 상태는 정착·호흡·하체 이완·상체 이완·심상·소실·여운의 7층으로 구성하고, 각 층에서 최근 사용한 조각을 일부 제외해 고릅니다. 새벽이나 요일에 맞는 조각은 조건이 맞을 때 후보에 합류합니다.

조합 수가 많아도 개별 문장은 다시 나옵니다. 매일 새 대본을 생성하는 방식은 아닙니다. 온천 이야기처럼 서사가 있는 여정은 같은 순서의 한 편을 재생하며, 감사의 밤은 조각을 조합합니다. 밤중에 깼을 때·낮잠·마음 가라앉히기는 더 짧은 구성을 사용합니다.

- 배경 소리 13종과 자연 배경 7종, 독립된 호흡 화면
- 미리 생성한 남성 나레이션을 문장 단위로 재생하고 문장 사이 침묵을 조절
- 취침 준비, 타이머와 알람, 밤 기록 및 낮잠 기록
- 기록한 날을 바탕으로 계산하는 최근 14일 수면 부족 추정치
- 서비스 워커를 통한 앱 파일 및 사용한 미디어 캐시

## 소리와 재생

배경 소리는 `synth.js`가 합성합니다. 현재 매니페스트의 모닥불·풀벌레는 기존 녹음 파일을 우선 사용하고, 불러오지 못하면 합성으로 전환합니다. 기존 녹음 출처는 [audio/LICENSES.md](audio/LICENSES.md)에 있습니다. 이번 개선에서는 외부 음원을 추가하지 않았습니다.

나레이션은 사전 생성한 VoxCPM2 남성 음성 파일이 기본입니다. 파일 경로가 없는 조각만 기기 내장 TTS를 사용합니다. 파일 재생 오류를 정상 완료로 처리하지 않고 오류 콜백을 전달합니다.

재생은 HTML 오디오 엘리먼트를 사용합니다. 배경음은 두 엘리먼트를 겹쳐 교대하며, iPhone에서 볼륨 조절이 적용되지 않는 경우 파형에 음량과 페이드를 반영합니다. 실제 잠금 화면에서의 장시간 재생은 기기별 확인이 필요합니다.

## 기록과 오프라인의 범위

잠든 시각이나 수면 단계를 측정하지 않습니다. 취침 시작과 기상 입력 사이에서 설정한 입면 시간(기본 15분)을 빼서 추정합니다. 기록하지 않은 날은 계산에 포함하지 않으며, 기록이 없다는 사실이 충분히 잤다는 뜻은 아닙니다. 미래 시각·잘못된 시간·무한값 기록은 계산에서 제외합니다.

기록은 현재 브라우저의 로컬 저장소에 남습니다. 앱 파일은 설치 시 캐시하고 나레이션은 사용하면서 저장합니다. 아직 받지 않은 음성까지 오프라인에서 재생할 수 있는 것은 아닙니다. 앱 파일 요청이 네트워크 오류나 HTTP 오류로 실패하면 저장된 파일을 사용합니다.

웹 알람은 브라우저가 종료되거나 운영체제가 재생을 제한하면 울리지 않을 수 있습니다. 반드시 일어나야 하는 날에는 기기 기본 알람을 함께 설정해야 합니다. App Store용 네이티브 앱이나 결제 기능은 현재 구현에 포함되어 있지 않습니다.

## 로컬 실행과 검증

빌드나 패키지 설치 없이 정적 파일과 ES 모듈로 실행합니다.

```sh
python -m http.server 8123
node test.js
```

`http://localhost:8123`에서 엽니다. `file://`에서는 ES 모듈과 fetch가 동작하지 않습니다. 테스트는 수면 계산·조각 선택·루프 페이드·오디오 재생 거부·오프라인 셸과 오류 응답 폴백을 검증합니다.

## 구조

```text
app.js        화면 전환 · 로컬 저장 · 세션
audio.js      믹서 · 나레이션 재생 · 알람
synth.js      배경 소리 합성 DSP
narration.js  층별 조립 · 최근 조각 회피
sleep.js      시간 추정 · 기록 계산 · 알람 감시
scenes.js     영상 교대 · 캔버스 배경
sw.js         앱 및 미디어 캐시
data/         나레이션과 소리 매니페스트
```

프로젝트 지침은 [CLAUDE.md](CLAUDE.md), 현재 작업과 미확인 항목은 [STATUS.md](STATUS.md)를 참조합니다. 배포는 별도 지시에 따라 진행합니다.
