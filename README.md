# 굿슬립

상태를 고르면 **매일 밤 다른 이야기**가 나오는 수면 웹앱.

👉 https://moonsujin0309.github.io/goodsleep/

## 왜 만들었나

Calm과 Renight를 쓰고 남은 불만이 하나로 모였다 — **반복**.
Renight는 AI가 매일 새로 만든다는데도 결국 똑같이 느껴졌다.
생성 여부가 아니라 체감 다양성이 문제다.

| | 가져온 것 | 버린 것 |
|---|---|---|
| Calm | 백색소음·자연음 믹서, 자연 배경 | 매번 같은 명상 |
| Renight | 상태별 나레이션, 수면부채 리포트 | 듣기 싫은 모노럴 비트, 반복되는 나레이션 |

## 어떻게 반복을 없애나

나레이션을 통짜 트랙이 아니라 **조각 3층으로 관리하고 매번 새로 조립한다.**

```
도입 4 × 본문 6 × 마무리 4  →  조각 14개로 조합 96개
```

여기에 "최근 나온 조각은 후보에서 제외" 규칙을 얹었다.
실측: 40회 연속 재생 시 **조합 34종, 연속 중복 0회.**

수면 나레이션은 원래 문장 사이가 침묵이라 조각 이음매가 그 침묵에 숨는다.

## 기능

- 상태 5종 선택 → 맞춤 나레이션 + 사운드
- 사운드 믹서 10종 (비·파도·모닥불·바람·시냇물·풀벌레·선풍기·백색/핑크/브라운 노이즈)
- 캔버스 배경 4종 + 호흡 가이드
- 수면 타이머 → 알람 → **수면부채 리포트** (14일 추이)
- 낮잠 기록 (타이머 / 수동 입력)
- 낮 세션: 마음 가라앉히기

## 소리는 전부 합성이다

음원 파일이 하나도 없다. 코드가 실시간으로 만든다 ([audio.js](audio.js)의 `generateBed`).

- **라이선스가 없다.** 무료 음원 라이브러리 대부분은 "소스 파일과 함께 재배포"를 금지해서 공개 저장소에 올릴 수 없다
- **루프 이음매가 없다.** 주기 성분을 루프 길이의 정수 배로 맞춰 파형이 수학적으로 이어진다. 녹음 루프가 몇 분마다 툭 끊기는 문제가 원천적으로 없다
- **0바이트.** 모바일 데이터로 즉시 열린다

레이어 음량은 피크가 아니라 **RMS 기준으로 정규화**했다. 사람 귀는 평균 에너지로 크기를 느끼기 때문에, 피크로 맞추면 같은 슬라이더 값에서 모닥불과 백색소음이 7배 차이로 들린다.

## 실행

빌드 없음. 정적 파일 + ES 모듈.

```bash
python -m http.server 8123
```

`file://` 로는 안 열린다 (ES 모듈과 fetch 때문에 서버가 필요하다).

```bash
node test.js    # 29개
```

## 한계

- **알람은 네이티브만큼 확실하지 않다.** 웹앱이라 브라우저가 탭을 완전히 종료하면 울리지 않는다. 밤새 무음 트랙을 돌려 탭을 살려두고 벽시계로 시각을 재계산하지만, 첫 며칠은 폰 기본 알람을 백업으로 함께 켜둘 것
- **잠든 시각은 감지할 수 없다.** 설정의 "잠드는 데 걸리는 시간"(기본 15분)을 침대에 누운 시간에서 빼서 계산한다. 실제와 다르면 조절하면 된다
- 나레이션 음성은 현재 브라우저 내장 TTS다. 미리 렌더한 mp3 로 교체할 수 있다 ([audio/README.md](audio/README.md))

## 구조

```
app.js        화면 전환 · 저장 · 세션
audio.js      사운드 합성 · 믹서 · 백그라운드 유지 · 알람
narration.js  조립 엔진 · 중복 회피      ← 순수 함수
sleep.js      수면부채 계산 · 알람 감시   ← 순수 함수
scenes.js     캔버스 비주얼
data/         나레이션 조각 · 사운드 레이어 매니페스트
```

콘텐츠는 `data/*.json` 만 고치면 된다. 코드에 상태별 분기가 없다.
