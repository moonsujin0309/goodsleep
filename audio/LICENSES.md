# audio/loops/ — 실제 녹음의 출처와 라이선스

공개 저장소이므로 여기 기록된 파일만 커밋한다. 새 파일을 넣으면 반드시 여기에 한 줄 추가할 것.

| 파일 | 원본 | 녹음자 | 라이선스 |
|---|---|---|---|
| `crickets.mp3` | [Les Cluses, Occitanië — Nighttime Crickets](https://archive.org/details/aporee_70514_82218) (radio aporee, Blumlein 스테레오 FLAC에서 120–185초 구간 발췌, 55Hz 하이패스) | Jillis Molenaar | [Public Domain Mark 1.0](https://creativecommons.org/publicdomain/mark/1.0/) — 녹음자 본인이 업로드하며 퍼블릭 도메인으로 표시 |
| `fire.mp3` | [Colonel's House (fireplace), Kłodzko — fireplace hiss and crackling](https://archive.org/details/aporee_60408_69385) (radio aporee, FLAC에서 4–80초 구간 발췌, 40Hz 하이패스) | Piotrek Zyla | [Public Domain Mark 1.0](https://creativecommons.org/publicdomain/mark/1.0/) — 녹음자 본인이 업로드하며 퍼블릭 도메인으로 표시 |

- 두 파일 모두 상업적 이용·수정·재배포에 제한이 없는 퍼블릭 도메인 표시 자료다.
  법적 의무는 없지만 녹음자와 출처를 위 표에 남긴다.
- CC BY / BY-SA 파일을 추가할 때는 저작자 표기(이 파일)와 라이선스 링크가 의무가 된다.
- 라이선스를 확인하지 못한 파일은 넣지 않는다 — `.gitignore` 가 오디오 확장자를 막고 있고,
  `audio/loops/*.mp3` 만 예외다.
