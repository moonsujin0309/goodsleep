# audio/

여기에 음원을 넣으면 코드 수정 없이 앱에 붙는다.

## loops/ — 배경 사운드

`data/sounds.json` 의 `file` 경로와 이름을 맞춰서 넣는다.

```
loops/rain.mp3      비
loops/waves.mp3     파도
loops/fire.mp3      모닥불
loops/wind.mp3      바람
loops/stream.mp3    시냇물
loops/crickets.mp3  풀벌레
loops/fan.mp3       선풍기
```

파일이 없는 레이어는 앱에서 "음원 없음"으로 흐리게 잠긴다. 넣는 즉시 켜진다.

- 무료 출처: Freesound(CC0) · Pixabay Audio · YouTube 오디오 보관함
- 길이는 2~5분이면 충분하다. 앱이 무한 반복한다
- **루프 이음매를 먼저 없애고 넣을 것.** 끝과 시작을 1초 정도 크로스페이드하지 않으면
  몇 분마다 툭 끊기는 소리가 나고, 조용한 방에서는 그게 제일 거슬린다
- 백색/핑크/브라운 노이즈는 코드가 만들어 쓰므로 파일이 필요 없다

## 나레이션

`data/narration.json` 의 조각마다 `"file": "audio/<상태>/<id>.mp3"` 를 추가한다.
`file` 이 있으면 파일이 우선하고, 없으면 `text` 를 브라우저 내장 TTS 가 읽는다.

```
racing/i1.mp3  anxious/b3.mp3  wired/o2.mp3  ...
```

### 뽑는 순서

1. `data/narration.json` 의 `text` 를 그대로 대본으로 쓴다
2. **문장 단위로 렌더한다.** 통으로 넣지 말 것 — 일반 TTS 모델은 긴 침묵을
   오류로 보고 자동으로 줄인다. 수면 나레이션은 그 침묵이 핵심이다
3. 문장 사이 무음 3~8초를 직접 삽입한다 (모델에 맡기지 않는다)
4. 볼륨을 일괄 노멀라이즈한다
5. 들어보고 발음이 어색한 것은 버리고 다시 뽑는다

톤 지시: 느리게, 낮게, 숨소리가 약간 섞이게. 또렷한 발음보다 부드러움 우선.

**`racing` 한 상태를 먼저 끝내서 품질을 확정한 다음** 그 설정을 나머지에 복제할 것.
전부 뽑아놓고 마음에 안 들면 다시 하는 게 제일 비싸다.
